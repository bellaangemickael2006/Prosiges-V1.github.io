      · son chiffre d'affaires augmente
      · son stock diminue

  LES TROIS CAUSES LES PLUS FRÉQUENTES
  ─────────────────────────────────────

  1. LES BIBLIOTHÈQUES GOOGLE NE SONT PAS INSTALLÉES
     C'est de loin la plus courante. Elles ne font pas partie de
     l'installation de base, pour que celle-ci ne puisse jamais
     échouer. Le lanceur les installe désormais tout seul dès qu'il
     voit un credentials.json — mais si vous avez ajouté ce fichier
     APRÈS la première installation, lancez :

         Windows   : .venv\Scripts\pip install -r requirements-google.txt
         Mac/Linux : ./venv/bin/pip install -r requirements-google.txt

  2. LE DOSSIER OU LE CLASSEUR N'EST PAS PARTAGÉ
     Ouvrez credentials.json, repérez la ligne « client_email »
     (du type xxx@xxx.iam.gserviceaccount.com). Dans Drive, partagez
     le dossier ET le classeur avec cette adresse, en ÉDITEUR.
     Lecteur ne suffit pas.

  3. LE COMPTE DE SERVICE N'A PAS D'ESPACE DE STOCKAGE
     Message : « Service Accounts do not have storage quota ».
     C'est une limite de Google : un compte de service ne peut pas
     CRÉER de fichier, seulement écrire dans un fichier existant.

     La solution :
       1. Dans VOTRE Drive : Nouveau → Google Sheets
       2. Partager → l'adresse du compte de service → ÉDITEUR
       3. Copiez l'identifiant depuis l'URL :
          docs.google.com/spreadsheets/d/IDENTIFIANT/edit
       4. Dans l'application : Entreprises suivies → Modifier →
          « ID du classeur de publication » → collez-le

     L'application écrira alors dans VOTRE classeur, dont vous
     restez propriétaire.


┌──────────────────────────────────────────────────────────────────────┐
│  UN COMPTE NE FONCTIONNE PLUS ?                                      │
└──────────────────────────────────────────────────────────────────────┘

  Mot de passe oublié, compte disparu, connexion refusée :

      python gerer_comptes.py liste
          → affiche tous les comptes et leur état

      python gerer_comptes.py reparer
          → recrée les comptes manquants et remet les mots de passe
            d'origine. AUCUNE donnée comptable n'est touchée.

      python gerer_comptes.py motdepasse <email> <nouveau_mot_de_passe>
          → change le mot de passe d'un compte précis

  (Sur Windows, remplacez « python » par « .venv\Scripts\python »
   si la commande n'est pas reconnue.)

  ÉTAPE 0 — CONTRÔLE DE SÉCURITÉ  (ne sautez pas cette étape)
  ────────────────────────────────────────────────────────────
    Lancez :

        python verifier_avant_github.py

    Ce script vérifie qu'aucun secret ne partira en ligne : clé
    Google, mot de passe, base de données. Il doit afficher
    « AUCUN PROBLÈME » avant de continuer.

    ⚠  Un secret publié sur GitHub — même dans un dépôt privé,
       même supprimé ensuite — doit être considéré comme compromis.
       Il reste dans l'historique du dépôt.


  ÉTAPE 1 — Mettre le code sur GitHub
  ────────────────────────────────────
    1. Créez un compte sur  https://github.com  (gratuit)
    2. Cliquez sur « New repository »
    3. Nom : akworld — laissez en « Private » si vous préférez
    4. Dans le dossier du projet, ouvrez un terminal et tapez :

           git init
           git add .
           git commit -m "Application AK World"
           git branch -M main
           git remote add origin https://github.com/VOTRE_COMPTE/akworld.git
           git push -u origin main

       Le fichier .gitignore exclut automatiquement les secrets,
       la base de données et l'environnement Python.

    5. Si vous préférez le glisser-déposer sur github.com, veillez à
       EXCLURE MANUELLEMENT : .venv, venv, ak_world.db, .env et
       credentials.json. La méthode Git est plus sûre.


  ÉTAPE 2 — Déployer sur Render
  ──────────────────────────────
    1. Créez un compte sur  https://render.com  (gratuit)
       → connectez-vous avec votre compte GitHub
    2. Cliquez sur  New  →  Blueprint
    3. Sélectionnez votre dépôt « akworld »
    4. Cliquez sur  Apply

    Render lit le fichier render.yaml et configure TOUT tout seul :
    le serveur, la base de données PostgreSQL, la clé de sécurité,
    les cookies sécurisés et le certificat HTTPS.

    Vous n'avez AUCUNE variable à saisir.

    Attendez 3 à 5 minutes. Votre adresse s'affiche en haut de page.


  ÉTAPE 3 — Première connexion
  ─────────────────────────────
    Ouvrez l'adresse, connectez-vous avec :
        gerant@akworld.com  /  AkWorld2026!

    ⚠  CHANGEZ LE MOT DE PASSE IMMÉDIATEMENT
       (onglet « Mon profil »)

    Le site en ligne démarre VIDE — sans les données de démonstration.
    C'est voulu : vous créez vos vraies entreprises clientes depuis
    l'onglet « Entreprises suivies ».

    Pour créer les comptes de votre équipe, deux possibilités :
      · depuis l'onglet « Utilisateurs » du site
      · ou en ligne de commande dans le shell Render :
